# Antigravity Workspace Design & Engineering Rule

## Trigger
- **Scope:** Workspace-wide
- **Trigger Type:** Always on for frontend UI, styling, and full-stack modifications.

## Rules
1. Read `DESIGN.md` in the project root before altering or introducing UI components.
2. Follow the 10-step `human-quality-frontend` workflow:
   - Understand $\rightarrow$ Research $\rightarrow$ Define $\rightarrow$ Implement $\rightarrow$ Humanize $\rightarrow$ Inspect $\rightarrow$ Critique $\rightarrow$ Refine $\rightarrow$ Verify $\rightarrow$ Report.
3. Reject generic AI design tropes:
   - No floating glowing gradient blur blobs behind cards.
   - No arbitrary rounded card partitions where tables, split lists, or tabbed ledgers are clearer.
   - No ungrounded statistical marketing counters.
   - No artificial AI prose or robotic headlines.
4. Execute real browser-based visual verification using browser automation or live rendering.
5. Apply ponytail restraint: keep components concise, cohesive, and directly tied to application logic.
